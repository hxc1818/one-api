🎯 核心功能
================================================================================

✅ 用户认证
   - 用户名/密码验证
   - 返回 JWT Token
   - 支持邮箱登录

✅ 余额管理
   - 查询用户余额
   - 发起扣款（带余额检查）
   - 回退扣款（防止重复回退）

✅ 交易记录
   - 完整的交易历史
   - 支持分页查询
   - 记录扣款和回退

✅ 用户日志集成 ⭐
   - 扣款操作写入 one-api 的 logs 表（LogTypeConsume）
   - 回退操作写入 one-api 的 logs 表（LogTypeTopup）
   - 用户可以在 one-api 界面看到来自 wallet-api 的操作
   - token_name 标记为 "wallet-api" 便于识别

✅ Redis Stream 事件推送 ⭐
   - 异步推送余额变更事件
   - 支持消费者组（Consumer Group）
   - 高性能，不阻塞主流程
   - 多订阅方可并行消费

✅ 订阅管理
   - 添加/删除订阅域名
   - 管理员权限控制

✅ 安全特性
   - JWT Token 认证
   - 事务保证数据一致性
   - 防止并发冲突
   - 不支持充值（仅扣款和回退）

🚀 快速部署（推荐使用 Docker）
================================================================================

【最简单的方式】
--------------------------
cd wallet-api/docker
cp .env.example .env
nano .env          # 配置数据库和 Redis
./deploy.sh        # 选择 1) Build and start

完成！访问 http://localhost:8081

【连接已有 one-api】
--------------------------
编辑 .env：
  SQL_DSN=root:password@tcp(your_host:3306)/oneapi?charset=utf8mb4&parseTime=True&loc=Local
  REDIS_CONN_STRING=redis://your_redis_host:6379/0
  JWT_SECRET=$(openssl rand -hex 32)

启动服务：
  docker-compose up -d wallet-api

================================================================================
📝 API 接口
================================================================================

POST   /api/v1/auth/verify      # 用户认证
GET    /api/v1/balance           # 查询余额
POST   /api/v1/deduct            # 发起扣款 ⭐
POST   /api/v1/refund            # 回退扣款 ⭐
GET    /api/v1/transactions      # 查询交易记录
POST   /api/v1/subscriptions     # 添加订阅（管理员）
DELETE /api/v1/subscriptions/:id # 删除订阅（管理员）
GET    /api/v1/subscriptions     # 列出订阅（管理员）

================================================================================
🔔 Redis Stream 事件格式
================================================================================

Stream Key: wallet:balance:updates

事件数据：
{
  "user_id": 1,
  "username": "user123",
  "balance_before": 1000000,
  "balance_after": 999900,
  "change_amount": -100,
  "type": "deduct",            // 或 "refund"
  "transaction_id": 123,
  "timestamp": "2024-01-01T12:00:00Z",
  "description": "API 调用费用"
}

消费方式：
  - XREAD: 简单模式
  - XREADGROUP: 消费者组（推荐）
  - 支持 ACK 确认机制

⚠️ 注意事项
================================================================================

1. 密码验证功能
   当前 service/wallet.go 中的 validatePasswordAndHash 是简化实现
   生产环境需要导入 one-api 的实际密码验证逻辑：
   import "github.com/songquanpeng/one-api/common"
   使用 common.ValidatePasswordAndHash(password, hash)

2. 数据库共享
   必须与 one-api 使用同一数据库，否则无法验证用户和写入日志

3. Redis 必需
   Redis 是必需依赖，用于事件推送

4. 不支持充值
   本 API 只能扣款和回退，不能直接充值
   充值请通过 one-api 的管理界面操作

5. 日志数据库
   支持配置独立的日志数据库（LOG_SQL_DSN）
   如果不配置则使用主数据库

🔄 工作流程
================================================================================

扣款流程：
  1. 客户端调用 POST /api/v1/deduct
  2. 验证 JWT Token
  3. 检查用户余额是否足够
  4. 开启数据库事务
     - 扣除用户余额
     - 写入 transactions 表
     - 提交事务
  5. 写入 one-api 的 logs 表（用户可见）⭐
  6. 推送事件到 Redis Stream
  7. 返回成功响应

回退流程：
  1. 客户端调用 POST /api/v1/refund
  2. 验证 JWT Token
  3. 查询原始扣款交易
  4. 检查是否已回退
  5. 开启数据库事务
     - 增加用户余额
     - 写入 transactions 表（标记为回退）
     - 提交事务
  6. 写入 one-api 的 logs 表（充值类型）⭐
  7. 推送事件到 Redis Stream
  8. 返回成功响应

订阅方消费：
  1. 创建消费者组
  2. 循环调用 XREADGROUP 读取事件
  3. 解析事件数据
  4. 执行业务逻辑（同步余额、发送通知等）
  5. 确认消息（XACK）
