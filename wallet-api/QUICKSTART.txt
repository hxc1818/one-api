🚀 30 秒快速部署
================================================================================

# 步骤 1: 进入 Docker 目录
cd wallet-api/docker

# 步骤 2: 配置环境变量
cp .env.example .env
nano .env

# 步骤 3: 一键部署
./deploy.sh

# 选择: 1) Build and start (full deployment)

完成！访问 http://localhost:8081/health

================================================================================
📋 必须配置的环境变量
================================================================================

在 .env 文件中修改以下配置：

SQL_DSN=root:password@tcp(localhost:3306)/oneapi?charset=utf8mb4&parseTime=True&loc=Local
REDIS_CONN_STRING=redis://localhost:6379/0
JWT_SECRET=$(openssl rand -hex 32)

提示：如果连接已有的 one-api，修改 SQL_DSN 指向你的数据库

================================================================================
🧪 测试 API
================================================================================

# 1. 健康检查
curl http://localhost:8081/health

# 2. 用户认证
curl -X POST http://localhost:8081/api/v1/auth/verify \
  -H "Content-Type: application/json" \
  -d '{"username":"root","password":"123456"}'

# 3. 查询余额（替换 YOUR_TOKEN）
curl -X GET http://localhost:8081/api/v1/balance \
  -H "Authorization: Bearer YOUR_TOKEN"

# 4. 扣款
curl -X POST http://localhost:8081/api/v1/deduct \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"amount":100,"description":"测试扣款"}'

🎯 核心功能
================================================================================

✅ 用户认证 + JWT Token
✅ 余额查询
✅ 发起扣款（写入用户日志）
✅ 回退扣款（写入用户日志）
✅ Redis Stream 事件推送
✅ 交易记录查询
✅ 订阅管理

用户可以在 one-api 界面看到来自 wallet-api 的扣款和退款记录！

================================================================================
💡 提示
================================================================================

1. 本 API 必须与 one-api 共享同一数据库
2. Redis 是必需的依赖
3. 不支持充值操作（仅扣款和回退）
4. 扣款操作会写入 one-api 的 logs 表，用户可见
5. 订阅方通过 Redis Stream 消费余额变更事件
