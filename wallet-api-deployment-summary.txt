================================================================================
🎯 核心功能实现
================================================================================

✅ 用户认证
   - 用户名/密码验证（支持邮箱）
   - JWT Token 生成和验证
   - 返回用户信息和余额

✅ 余额管理
   - 查询用户余额
   - 发起扣款（带余额检查）
   - 回退扣款（防止重复回退）
   - 数据库事务保证一致性

✅ 用户日志集成 ⭐ 重要特性
   - 扣款操作 → 写入 one-api logs 表（LogTypeConsume）
   - 回退操作 → 写入 one-api logs 表（LogTypeTopup）
   - token_name 标记为 "wallet-api"
   - 用户可在 one-api 界面查看操作记录

✅ Redis Stream 事件推送 ⭐ 高性能特性
   - 异步推送余额变更事件
   - 支持消费者组（Consumer Group）
   - 不阻塞主流程（性能优秀）
   - 多订阅方可并行消费

✅ 交易记录
   - 完整的交易历史记录
   - 支持分页查询
   - 包含前后余额快照
   - 支持关联原始交易（回退）

✅ 订阅管理（管理员功能）
   - 添加/删除订阅域名
   - 管理员权限控制
   - 支持启用/禁用

================================================================================
🚀 快速部署（3 步）
================================================================================

【步骤 1】进入 Docker 目录
cd wallet-api/docker

【步骤 2】配置环境变量
cp .env.example .env
nano .env

必须配置：
  - SQL_DSN: 数据库连接（必须与 one-api 共享）
  - REDIS_CONN_STRING: Redis 连接
  - JWT_SECRET: JWT 签名密钥

【步骤 3】运行部署脚本
./deploy.sh
选择: 1) Build and start (full deployment)

完成！服务运行在: http://localhost:8081

📝 API 接口列表
================================================================================

认证接口：
  POST   /api/v1/auth/verify          # 用户认证

余额和交易：
  GET    /api/v1/balance               # 查询余额
  POST   /api/v1/deduct                # 发起扣款 ⭐
  POST   /api/v1/refund                # 回退扣款 ⭐
  GET    /api/v1/transactions          # 查询交易记录

订阅管理（管理员）：
  POST   /api/v1/subscriptions         # 添加订阅
  DELETE /api/v1/subscriptions/:id     # 删除订阅
  GET    /api/v1/subscriptions         # 列出订阅

健康检查：
  GET    /health                        # 健康检查

================================================================================
🔔 Redis Stream 事件
================================================================================

Stream Key: wallet:balance:updates

事件格式：
{
  "user_id": 1,
  "username": "user123",
  "balance_before": 1000000,
  "balance_after": 999900,
  "change_amount": -100,
  "type": "deduct",              // 或 "refund"
  "transaction_id": 123,
  "timestamp": "2024-01-01T12:00:00Z",
  "description": "API 调用费用"
}

消费方式：
  - 使用 XREAD（简单模式）
  - 使用 XREADGROUP（推荐，支持消费者组）
  - 示例代码：examples/consumer-example.md

================================================================================
⚠️ 重要注意事项
================================================================================

1. 密码验证
   当前 validatePasswordAndHash 是简化实现
   生产环境需导入 one-api 的密码验证逻辑

2. 数据库共享
   必须与 one-api 使用同一数据库

3. Redis 必需
   Redis 是必需依赖，用于事件推送

4. 不支持充值
   仅支持扣款和回退，充值请通过 one-api 管理界面

5. 日志可见性
   扣款和回退操作会写入 one-api 的 logs 表
   用户可在 one-api 界面查看操作记录
