🚀 三步部署：
========================================

步骤 1: 上传到服务器
-------------------
scp -r ./docker user@your-server:/opt/one-api/

步骤 2: 一键部署
-------------------
ssh user@your-server
cd /opt/one-api
chmod +x deploy.sh
./deploy.sh

步骤 3: 访问服务
-------------------
浏览器打开: http://your-server:3000
用户名: root
密码: 123456

⚠️ 首次登录后立即修改密码！

========================================
✨ 使用 Codex 功能：
========================================

1. 登录后台 -> 令牌页面
2. 新建令牌 -> 选择"Codex 格式（自动转换 /v1/responses）"
3. 保存并复制密钥

4. 测试请求：
   curl -N http://your-server:3000/v1/responses \
     -H "Authorization: Bearer sk-your-key" \
     -H "Content-Type: application/json" \
     -d '{
       "model": "gpt-4",
       "input_items": [{
         "type": "message",
         "role": "user",
         "content": [{"type": "text", "text": "Hello"}]
       }],
       "stream": true
     }'
